# 功能模块

本章节详细介绍组织效能管控平台的核心功能模块，包括每个模块的业务目标、主要功能和使用方法。

## 核心功能模块

### [人员档案管理](personnel-archive.md)

完整的人员档案信息管理系统，包括档案管理、档案审核、面试管理等功能。

### [智能标签体系](tag-management.md)

提供岗位描述管理、组织标签管理、标签匹配与规则配置等功能，支持标签审核机制。

### [策略管理](strategy.md)

包括目标管理、目标分解、指标库管理、计划管理等功能，支持目标确认和填报。

### [系统管理](system.md)

提供用户管理、角色管理、菜单管理、部门管理等系统基础功能。

### [组织大脑](org-brain.md)

提供组织部署管理、岗位图谱、岗位匹配分析等智能化功能。

### [文件中心](file-center.md)

提供文件上传与管理、导入导出等功能。

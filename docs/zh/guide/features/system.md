# 系统管理

系统管理模块是组织效能管控平台的基础功能之一，提供用户管理、角色管理、菜单管理、部门管理等系统基础功能。

## 功能概述

本模块旨在帮助管理员对系统进行全面的管理和配置，包括用户权限管理、系统菜单配置、部门结构管理等，确保系统的安全和稳定运行。

## 核心功能

### 用户管理

- **用户信息维护**：支持添加、编辑、删除用户信息，包括用户名、密码、部门、岗位等
- **用户权限管理**：配置用户的系统权限，包括页面访问权限和功能操作权限
- **用户状态管理**：管理用户的启用和禁用状态，支持批量操作

### 角色管理

- **角色创建与维护**：支持创建和维护系统角色，定义角色的权限范围
- **角色权限配置**：为角色分配页面访问权限和功能操作权限
- **角色用户管理**：管理角色与用户的关联关系，支持批量分配

### 菜单管理

- **菜单结构配置**：配置系统的菜单结构，包括菜单项的名称、路径、图标等
- **菜单权限控制**：设置菜单项的访问权限，控制不同用户角色的菜单可见性
- **菜单排序管理**：调整菜单项的显示顺序

### 部门管理

- **部门结构维护**：管理组织的部门结构，支持添加、编辑、删除部门
- **部门人员管理**：管理部门与人员的关联关系
- **部门层级管理**：支持多级部门结构的管理

## 技术实现

- 使用 React Hooks 和 TypeScript 实现组件开发
- 使用 Ant Design 和 @ant-design/pro-components 构建用户界面
- 使用 @tanstack/react-query 管理数据请求和缓存
- 使用 Mock Data 提供模拟接口数据

# 策略管理

策略管理模块是组织效能管控平台的核心功能之一，提供目标管理、目标分解、指标库管理、计划管理等功能，支持目标确认和填报。

## 功能概述

本模块旨在帮助组织实现战略目标的有效管理和执行，通过目标分解、指标配置、计划制定等功能，确保战略目标能够层层落实到具体的执行层面。

## 核心功能

### 目标管理

- **目标创建与维护**：支持创建和维护组织的战略目标，包括目标名称、描述、时间周期等
- **目标分解**：支持将战略目标分解为具体的子目标和指标，形成完整的目标体系
- **目标确认与审核**：提供目标的确认和审核流程，确保目标的合理性和可行性

### 指标库管理

- **指标配置**：支持配置各类业务指标，包括指标名称、计算方式、数据来源等
- **指标库维护**：管理组织的指标库，支持指标的分类和层级管理
- **指标数据分析**：提供指标数据的分析和可视化功能，支持指标趋势分析

### 计划管理

- **计划创建与维护**：支持创建和维护各类执行计划，包括计划名称、时间周期、责任部门等
- **计划执行跟踪**：跟踪计划的执行进度，支持计划调整和优化
- **计划考核与评估**：提供计划的考核和评估功能，支持绩效评价

## 技术实现

- 使用 React Hooks 和 TypeScript 实现组件开发
- 使用 Ant Design 和 @ant-design/pro-components 构建用户界面
- 使用 @tanstack/react-query 管理数据请求和缓存
- 使用 ECharts 实现数据可视化功能
- 使用 @dnd-kit 实现拖拽功能

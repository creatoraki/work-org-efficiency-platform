# 文件中心

文件中心模块是组织效能管控平台的基础功能之一，提供文件上传与管理、导入导出等功能。

## 功能概述

本模块旨在帮助组织高效管理各类文件资源，包括文件的上传、下载、存储、分类和权限管理等功能，支持批量操作和导入导出。

## 核心功能

### 文件上传与管理

- **文件上传**：支持单文件和多文件上传，支持拖拽上传和断点续传
- **文件存储**：提供安全可靠的文件存储功能，支持文件的版本管理
- **文件分类**：支持文件的分类和标签管理，方便文件的查找和检索
- **文件权限**：设置文件的访问权限，控制不同用户对文件的操作权限

### 文件导入导出

- **批量导入**：支持批量导入文件数据，支持 Excel、CSV 等格式
- **批量导出**：支持批量导出文件数据，支持 Excel、CSV 等格式
- **导入导出记录**：记录文件导入导出的历史记录，方便追溯和审计

### 文件搜索与预览

- **文件搜索**：提供强大的文件搜索功能，支持按文件名、关键词、分类等条件搜索
- **文件预览**：支持常见文件格式的在线预览，如 Word、Excel、PDF 等
- **文件分享**：支持文件的分享功能，生成分享链接并设置有效期

## 技术实现

- 使用 React Hooks 和 TypeScript 实现组件开发
- 使用 Ant Design 和 @ant-design/pro-components 构建用户界面
- 使用 @tanstack/react-query 管理数据请求和缓存
- 使用 WebSocket 实现实时消息通知
- 使用 Mock Data 提供模拟接口数据

# 智能标签体系

智能标签体系是组织效能管控平台的核心功能之一，提供岗位描述管理、组织标签管理、标签匹配与规则配置等功能，支持标签审核机制。

## 功能概述

本模块旨在帮助组织建立完善的标签体系，实现对人员、岗位和组织的精细化管理和智能匹配。通过智能标签，可以更准确地进行人员画像、岗位匹配和组织分析。

## 核心功能

### 岗位描述管理

- **岗位描述维护**：支持添加、编辑、删除岗位描述信息，包括岗位名称、职责、要求等
- **岗位描述审核**：提供岗位描述的审核流程，确保信息的准确性和完整性
- **岗位描述导入导出**：支持批量导入和导出岗位描述信息

### 组织标签管理

- **标签中心**：集中管理所有组织标签，支持标签的分类和层级管理
- **标签审核**：提供标签的审核流程，确保标签的质量和合规性
- **标签规则配置**：支持配置标签的生成规则和匹配规则

### 标签匹配与规则配置

- **标签匹配模型**：提供智能标签匹配模型，支持人员与岗位的自动匹配
- **规则库管理**：管理标签匹配的规则库，支持规则的添加、编辑和删除
- **匹配结果分析**：提供标签匹配结果的分析和可视化功能

## 技术实现

- 使用 React Hooks 和 TypeScript 实现组件开发
- 使用 Ant Design 和 @ant-design/pro-components 构建用户界面
- 使用 @tanstack/react-query 管理数据请求和缓存
- 使用 @dnd-kit 实现拖拽功能
- 使用 Mock Data 提供模拟接口数据

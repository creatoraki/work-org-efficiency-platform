# 人员档案管理

人员档案管理模块是组织效能管控平台的核心功能之一，提供完整的人员档案信息管理、审核流程和面试管理功能。

## 功能概述

本模块旨在帮助组织高效管理员工的完整档案信息，包括基本信息、工作经历、教育背景、技能证书等，并提供完善的审核流程和面试管理功能。

## 核心功能

### 档案管理

- **档案信息维护**：支持添加、编辑、删除人员档案信息，包括基本信息、工作经历、教育背景、技能证书等
- **档案查询与筛选**：提供灵活的查询和筛选功能，支持按部门、岗位、标签等条件查询人员档案
- **档案导入导出**：支持批量导入和导出人员档案信息，方便数据迁移和备份

### 档案审核

- **审核流程管理**：支持自定义档案审核流程，设置审核节点和审核人员
- **待审核档案管理**：集中管理待审核的档案信息，支持批量审核操作
- **审核历史记录**：记录档案审核的完整历史记录，方便追溯和审计

### 面试管理

- **面试任务分配**：支持创建面试任务并分配给相关人员
- **面试流程管理**：提供完整的面试流程管理，包括简历筛选、初面、复面、终面等环节
- **面试记录管理**：记录面试过程中的详细信息和评价，支持面试结果反馈

## 技术实现

- 使用 React Hooks 和 TypeScript 实现组件开发
- 使用 Ant Design 和 @ant-design/pro-components 构建用户界面
- 使用 @tanstack/react-query 管理数据请求和缓存
- 使用 ECharts 实现数据可视化功能
- 使用 Mock Data 提供模拟接口数据

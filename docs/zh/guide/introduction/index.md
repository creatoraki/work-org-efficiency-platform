# 介绍 {#instroduction}

组织效能管控平台是一个基于 React Hooks、TypeScript、Vite 和 Ant Design 构建的**现代化企业级中后台管理系统**。它专注于组织管理、人员效能和智能决策，提供完整的人员档案管理、智能标签体系、策略管理、系统管理等核心功能。

平台内置权限校验、动态菜单、多主题配置、路由缓存、颗粒化按钮级别权限控制、代码规范等开箱即用功能，让开发人员可以专注于业务开发而非基础架构搭建。

## 核心功能

### 人员档案管理

- 完整的人员档案信息管理
- 档案审核流程
- 面试管理
- 个人档案维护

### 智能标签体系

- 岗位描述管理
- 组织标签管理
- 标签匹配与规则配置
- 标签审核机制

### 策略管理

- 目标管理
- 目标分解
- 指标库管理
- 计划管理

### 系统管理

- 用户管理
- 角色管理
- 菜单管理
- 部门管理

### 组织大脑

- 组织部署管理
- 岗位图谱
- 岗位匹配分析

### 文件中心

- 文件上传与管理
- 导入导出功能

项目使用的技术栈先进且成熟，包含各个方面的最佳实践，既可以作为企业级应用的基础模板，也可以作为学习现代化前端开发的优质素材。

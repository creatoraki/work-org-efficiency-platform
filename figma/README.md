## 页面归属

所有整屏设计图均属于 **绩效管理 > 年终述职** 页面（左侧菜单「绩效管理」展开下的「年终述职」，与「年度评级」同级），包含：

- **述职列表页**：组织架构树 + 文件夹面板 + 概览与筛选 + 筛选区 + 人员卡片区 + 分页；
- **述职详情抽屉**：列表页右侧展开的人员详情（述职前·备课材料 / 述职中·录音转写 / 述职后·评分报告 三步），支持全屏。

代码对应：仓内现有 `src/pages/performance-management/`（绩效管理/年度评级）模块；「年终述职」页面尚未实现，本设计稿为其新建页面的视觉与交互依据。

## 相对 11-16 版本的主要变化

1. **新增整屏**：图 02「防重复录制提示弹窗」（其他账号已开启该人员述职时点击提示）；图 09「新增文件夹成功——全局提示」（提示 3 秒消失，点击蓝色文字自动定位至该文件夹）。
2. **抽屉状态重排**：旧「述职中」节点 `10811:650685` 已被替换。现详情合集按画布顺序为：待述职（16）→ 述职中·录音完成待提交（17，新增）→ 报告生成中·空态插图（18，新增）→ 报告生成中·含生成说明（19）→ 报告已生成（20）。
3. **待述职抽屉底栏**（16/21）：新增说明文案「备课材料已从千问办公同步，评委可提前查看;点『开始述职』进入录音转写」，主按钮为「开始述职」。
4. **报告已生成抽屉**（20）：底栏主按钮为「下载报告」，工具栏新增下载 icon。
5. **新增规范板**（22）：标签按钮状态合集——四态标签（述职中带呼吸动态光圈）+ 卡片操作按钮（结束录音/开始述职/查看进度/查看报告）+ 批量操作下拉（批量移动/批量下载）+ 本人正在录制时点击他人的提示弹窗。
6. **文件夹卡片规范**（24）更新：新增「点击」「输入」态（编辑输入框）。
7. **新增素材**：树-单选节点三例（27–29）；母组件人员卡片两例（30–31，序号 1 与 100、述职日期与述职时间两种文案）；状态标签组件集（32）。
8. 左侧菜单名为「述职管理」（绩效管理下，与年度评级同级），页签为「年终述职」。
